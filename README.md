# HTML

Este repositório contém projetos e exemplos utilizando **HTML** com foco na criação de páginas web simples e responsivas.

## Tecnologias Utilizadas
- **HTML**: Linguagem de marcação para estruturação de conteúdo web.
- **CSS**: Utilizado para estilização e responsividade.
- **JavaScript**: Para adicionar interatividade às páginas.

## Como Usar
1. Clone este repositório:
    ```bash
    git clone https://github.com/vexedray/html.git
    ```

2. Navegue até o diretório do projeto:
    ```bash
    cd html
    ```
